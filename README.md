# South Plus +++

一个面向 South Plus 系列站点的本地用户脚本，用于优化论坛浏览、帖子阅读、首页布局、快速导航和本地屏蔽体验。

## 当前版本

- `0.4.0`

## 安装方式

1. 安装 Tampermonkey、Violentmonkey 或其他兼容的用户脚本管理器。
2. 导入 `southplus_enhancer.user.js`。
3. 打开匹配站点页面后，脚本会在页面加载完成时自动运行。

## 更新方式

1. 打开脚本管理器中的 `South Plus +++` 编辑页。
2. 用仓库内最新的 `southplus_enhancer.user.js` 覆盖原脚本内容并保存。
3. 确认脚本头部 `@version` 已更新为 `0.4.0`。
4. 刷新已打开的 South Plus 页面，确认右下角工具栏显示最新入口。

> 当前脚本没有配置远程 `@updateURL` / `@downloadURL`，因此自动更新依赖脚本管理器保存后的本地版本；如果只是修改仓库文件，需要同步到脚本管理器后才会在浏览器中生效。

## 功能列表

### 页面与布局优化

- 清爽模式：隐藏友情链接、在线用户等低频模块。
- 站点外壳优化：默认使用清爽产品型浅色主题，主导航、首页 / 论坛 / 阅读页导航中心、内容区、论坛列表和阅读页按屏幕大小自适应，并限制大屏最大宽度，避免论坛目录横向拉散。
- 社区论坛任务页：接入左侧导航中心，兼容原站内层包裹结构，任务功能简介 / 操作 / 版权收进正文侧栏，任务列表数据保留在正文主列，避免被全局卡片样式撑出屏幕。
- 夜间模式：可在工具箱或设置面板切换深色影院式主题，阅读页、图集、灯箱和资源面板会同步改为低亮度界面。
- 阅读排版优化：帖子正文使用更清晰的适中字号和更紧凑行高，沉浸阅读下同步放大正文，同时优化卡片宽度、正文间距和图片展示。
- 统一弹层体系：工具箱、设置面板、稍后看 / 最近浏览 / 购买记录 / 资源工作台使用一致的圆角、阴影、按钮和移动端底部抽屉布局。
- 帖子页沉浸全屏：在阅读页启用更聚焦的全屏阅读布局。
- 阅读页紧凑模式：压缩用户资料区和帖子卡片占用空间。
- 隐藏头像资料：减少帖子左侧用户信息区域干扰。
- 长引用折叠：自动折叠较长引用块，并提供“展开引用”按钮。

### 首页增强

- 论坛仪表盘：首页模块前新增本地总览，汇总今日浏览、收藏新增、未读收藏、资源新增、稍后看积压和网络请求状态，并按站内收藏 / 稍后看 / 阅读进度 / 资源记录综合评分展示值得回看的主题。
- 首页模块全屏：将首页板块模块整理到导航中心右侧的全宽内容列，避免模块半宽错位。
- 左侧导航中心：首页模块、站点入口、已发现子栏目和当前页面路径统一收纳在左侧常驻导航中，只保留导航文字；导航密度可在设置面板切换，支持搜索导航项、星标置顶和一级分组折叠 / 展开，相关状态保存在本地，移动端改为横向滚动入口。
- 首页模块定位：导航中心会收集真实首页模块标题，例如漫区特设、蜜柑计划、综合交流等子栏目，并写入本地导航池，论坛列表页和阅读页也会保留这些入口；论坛子版块会按父级版块缩进展示，并过滤图墙模式等视图切换链接，避免菜单重复堆叠。
- 模块折叠：每个首页模块可单独折叠或展开。
- 今日活跃标记：对今日有新帖的板块显示数量徽标。

### 帖子列表增强

- 已读状态记录：打开帖子后自动记录为已读。
- 只看未读：论坛列表可临时隐藏已读主题。
- 稍后看：在帖子列表中将主题保存为本地关注，并显示星标。
- 稍后看中心：通过工具栏统一查看、搜索、筛选、标签分组、继续阅读、上次楼层、批量移除筛选结果、移除或清空已保存主题，打开状态下阅读进度会自动刷新。
- 可见稍后：将当前筛选后仍可见的主题批量加入稍后看。
- 本地屏蔽标题：可将标题关键词加入本地屏蔽规则。
- 本地屏蔽作者：可将作者加入本地屏蔽规则。
- 临时隐藏：支持隐藏当前行。
- 站内收藏：帖子列表行内 `收藏` 可直接收藏到站点收藏夹，悬停预览弹层也可一键收藏当前帖子。
- 列表筛选：支持按关键词、排除词和作者过滤当前列表。
- 子栏目导航：论坛列表页会收集当前页真实子版块链接加入左侧导航中心，阅读页会收集面包屑里的当前版块 / 子版块，并跨页面保留已发现导航；同一父级下去重、父子层级展示，移动端自动收为横向入口。
- 预载下页：手动预取下一页列表内容，减少后续翻页等待。
- 悬停预览：鼠标悬停主题标题时，尝试加载帖子文字和图片预览；0.3.0 起会缓存近期预览，并在站点提示 504 / 520 或操作频繁时临时暂停后台预览请求；0.3.1 起预览弹层可直接打开帖子、加入稍后看或复制链接，0.3.3 起可直接收藏到站点收藏夹，缓存命中、加载中、失败和冷却状态会显示在弹层顶部。
- 网络友好模式：默认开启，仅限制脚本主动发起的后台增强请求；导航中心刷新、悬停预览、预载下页、快捷回复刷新和自动购买刷新会统一排队、识别 429 / 503 / 504 / 520 限流或源站错误并进入冷却，正常打开帖子和翻页不被接管。

### 帖子阅读增强

- 自动标记已读：进入帖子详情页后保存主题已读状态。
- 阅读进度记录：在阅读页保存页码、滚动位置、阅读百分比、楼层位置和标签，稍后看中心、最近浏览或首楼工具可一键继续阅读、跳到未读楼层或上次楼层。
- 最近浏览：按最近阅读时间展示帖子历史，支持搜索、筛选、标签分组、继续阅读、上次楼层、批量移除筛选结果、打开、移除和清空。
- 自动购买低价帖子：可设置最高 SP 价格；当帖子价格严格低于上限且账户余额足够时，自动购买并无刷新更新帖子内容；购买成功后会识别新露出的磁力、电驴、种子、压缩包、百度网盘、其他云盘和外链并提供快捷跳转 / 复制入口，同时自动保存到资源工作台，并按帖子 / 楼层记录执行状态以避免刷新后重复触发。0.3.0 起余额检查会短时间缓存，购买和刷新请求会进入高优先级队列，避免和后台请求在同一秒内集中发出。
- 自动购买记录中心：展示自动购买检查、跳过、购买中、完成和失败记录，支持搜索、状态筛选、批量删除筛选结果、打开帖子、删除单条记录或清空全部记录。
- 资源工作台：通过工具栏 `源` 统一管理保存过的磁力、电驴、种子、压缩包、网盘和外链，支持搜索、按状态 / 类型 / 标签筛选、按来源帖分组、勾选批量处理、复制 Markdown 清单、添加备注 / 标签、复制待下载队列、导出资源清单、来源帖跳转和清理。
- 只看楼主：阅读页可隐藏非楼主回复。
- 屏蔽此人：在帖子楼层工具中快速加入作者屏蔽规则。
- 复制楼层链接：快速复制当前楼层链接。
- 资源链接提取：阅读页每楼工具可打开资源面板，提取磁力、电驴、种子、压缩包、百度网盘、其他云盘、图片和外链，支持还原论坛外链跳转包装、识别提取码 / 访问码 / 解压码，并按本楼、作者或类型筛选后复制或保存到资源工作台。
- 作者悬浮卡片：悬停作者区域时展示页面中可提取的作者信息。
- 预览图集中显示：聚合当前页正文图片，进入帖子时默认收起到右侧，支持首批渲染、滚动或按钮加载更多、侧栏 / 瀑布流布局、灯箱缩略图导航、键盘切图、缩放、复制原图地址、复制全部图片链接、按楼层复制、复制 Markdown 清单和只看大图。
- 空白分隔清理：隐藏帖子页中无内容的分隔节点。

### 回复增强

- 快捷回复：在帖子页或回复页展示常用回复按钮。
- 自定义回复语句：可在设置面板中编辑快捷回复列表，每行一条。
- 无刷新提交：点击快捷回复或页面原生提交按钮后，会跟随服务端回复落点局部加载最新楼层，不刷新整页。

### 导航与工具栏

- 页面导航中心：首页、论坛列表页、阅读页、最新帖子、搜索结果、个人中心全页签和社区论坛任务页在桌面端左侧常驻 `导航中心`，固定保留站点入口和本地导航池里的已发现子栏目；顶部搜索框可过滤导航项，星标可将常用入口复制到 `置顶导航`，一级分组标题可点击折叠 / 展开并保留状态；阅读页额外显示当前位置和上一主题 / 下一主题，首页模块、搜索、个人中心、任务页正文、阅读页面包屑和帖子内容会收进安全宽度，避免左栏遮挡内容或卡片溢出。
- 我的收藏主导航：主导航右侧新增 `我的收藏` 高频入口，直达站内收藏页；徽标会短期缓存站内收藏数量，减少刷新页面时对收藏页的额外读取；展开后按站内收藏 / 本地稍后看分组展示，支持搜索、最近 / 未读 / 资源 / 图片 / AI 快捷筛选、排序、复制链接、单条删除站内收藏、勾选后批量删除站内收藏和分批加载，收藏很多时不会一次性渲染全部记录。
- 悬浮工具栏：右下角保留 `顶部`、`底部`、`工具`、`设置` 四个高频入口，减少按钮堆叠。
- 工具箱：点击 `工具` 打开分组面板，按页面导航、阅读模式、我的中心和设置展示完整功能名称与用途说明；工具箱和设置面板互斥显示。
- 页面导航：支持上一页、下一页、最新帖子和论坛首页入口。
- 阅读模式：集中切换清爽模式、夜间模式、阅读排版、隐藏广告、首页模块、沉浸阅读、预览图集、只看未读和只看楼主。
- 我的中心：统一打开稍后看、最近浏览、自动购买记录和资源工作台。
- 键盘翻页：论坛列表页支持左右方向键切换上一页 / 下一页。

### 广告与干扰项处理

- 隐藏广告链接：识别淘宝、天猫、阿里妈妈等广告链接并隐藏。
- 隐藏广告图片：识别广告图片来源并隐藏。
- 清理广告容器：当表格行、单元格或区块主要由广告组成时一并隐藏。

## 本地数据

脚本不依赖远程服务，也不会上传个人配置。以下数据仅保存到当前浏览器的 `localStorage`：

- 脚本设置
- 已读主题记录
- 稍后看 / 关注主题记录（可附加标签）
- 阅读进度记录（含页码、滚动位置、百分比、楼层位置和标签）
- 标题屏蔽关键词
- 作者屏蔽关键词
- 快捷回复语句
- 自动购买执行记录
- 资源库记录（磁力、电驴、种子、压缩包、网盘、外链、处理状态、备注和标签）
- 导航池记录（已发现的首页模块、论坛子栏目和版块路径）
- 导航置顶记录

设置面板支持导出 / 导入 JSON 备份，备份会包含上述本地数据；导入前会预览备份内的数据数量，导入会覆盖当前浏览器内同类本地数据。`数据健康` 可统计本地数据并清理重复稍后看、重复 / 过期阅读进度、异常自动购买记录和异常资源记录；`本地体积` 面板会按 localStorage 类别展示占用大小、记录数量、上限比例和清理建议，方便在脚本变慢前先导出备份并清理。

## 发布前验证

发布或同步到脚本管理器前建议执行：

```bash
node --check southplus_enhancer.user.js
node southplus_enhancer.test.js
git diff --check
```

浏览器内建议抽查：

- 首页 / 论坛列表 / 阅读页 / 最新帖子 / 搜索结果 / 个人中心全页签 / 社区论坛任务：桌面宽度下左侧导航中心保留站点入口和全部已发现子栏目，首页 `论坛仪表盘` 显示关键指标、值得回看的主题、最近动态和资源速览；个人首页 / 资料 / 主题 / 回复 / 收藏 / 好友 / 商品 / 消息 / 设置都显示导航中心；主导航 `我的收藏` 可打开站内收藏页和快速面板，并自动读取“站内收藏 + 稍后看”的总数，加载前显示 `...`；阅读页面包屑、帖子表格、楼层工具条和正文右侧不横向溢出；任务页会把说明 / 操作 / 版权和真实任务列表拆成侧栏 + 主列，移动宽度下导航中心变为横向滚动入口。
- 夜间模式：通过工具箱 `夜` 或设置面板切换后，正文、列表、设置 / 工具弹层、图集、灯箱和资源工作台无明显白底残留。
- 列表页工具栏：确认快速过滤、`隐藏`、`收藏`、`可见稍后`、`预载下页` 可用，悬停预览弹层也显示 `收藏`。
- 阅读页工具栏：确认 `顶部`、`底部`、`工具`、`设置` 可用，`工具` 和 `设置` 弹出层互斥；工具箱内 `稍后看`、`最近浏览`、`购买记录`、`资源工作台` 面板可打开，并可搜索、按标签筛选、切换来源分组、勾选资源、复制 Markdown 清单、复制待下载队列、导出资源清单、批量处理当前筛选结果。
- 阅读页楼层工具：确认 `资源` 可打开资源面板，并可按本楼、作者或类型复制 / 保存链接；自动购买成功后抽查资源跳转提示、复制全部、资源面板和资源工作台入口。
- 设置面板：确认 `网络友好模式` 默认开启，`数据健康` 可展示统计和清理异常数据，`本地体积` 可展示各类 localStorage 占用、记录上限比例和清理建议，备份导入前会显示数据预览。
- 阅读进度：确认达到 `100%` 后不会回退，`继续阅读`、`未读楼层` 和 `上次楼层` 可跳转到预期位置。
